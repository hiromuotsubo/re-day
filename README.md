# re:day

毎日届く2枚の思い出と、スクロールしながら眺めるチェキのアルバム。ログインは不要です。サンプル18枚から始めて、自分の写真・撮影日・場所・コメント・タグをこのブラウザに保存できます。

## 起動

Node.js 22.12 以降と npm を使用します。リポジトリのディレクトリで実行してください。

```sh
npm ci
npm run dev
```

ターミナルに表示されるURLを開きます。本番用は `npm run build` で生成される `dist/` を静的サーバーに配置します。`npm run preview` でビルド結果を確認できます。ローカルホストまたはHTTPSで利用してください。

## 写真を残す・振り返る

- 「今日の2枚」は端末のローカル日付で抽選します。自分の写真を優先し、足りない分はサンプルから選びます。当日のIDをlocalStorageに保存します。
- 「眺める」はチェキを左右交互に、「一覧」はデスクトップで3列、タブレット・スマートフォンで2列に並べます。写真の種類・タグ・並び順は表示の切替後も共通です。「再シャッフル」はアルバムだけに適用されます。
- 「写真を追加」から1枚選ぶかドロップし、任意の情報を入力して保存します。対応形式はJPEG、PNG、WebP、GIF、AVIFです。読み込みにはブラウザの形式対応が必要です。
- チェキを押すと手前で裏返り、撮影日・場所・コメント・タグを読めます。「写真を見る」で表面に戻すと、写真全体を元の縦横比で表示します。
- 自分のチェキの裏面で「編集」を選ぶと、写真の差し替え、撮影日の訂正、文章やタグの変更ができます。「削除」は確認後に実行します。サンプルは閲覧専用です。

## 保存と移行

写真は元ファイルのままBlobとして、登録情報と一緒にIndexedDBの `re-day / memories` に保存します。Blobの書き込みに対応しない環境では、同じ画像のバイト列と形式を保存し、読み込み時にBlobへ戻します。正方形の切り抜きはカード表示だけで、詳細では元の縦横比で表示します。サンプルは静的ファイルです。画像・フォント・ZIP処理を含め、利用者が登録した写真を送信する処理はありません。

保存先はブラウザのプロファイルとサイトのオリジンごとに分かれます。別端末・ブラウザとは自動同期されず、ブラウザデータの消去で写真を失うことがあります。同じプロファイルを使う人は写真を閲覧できます。

ヘッダーの設定、またはフッターの「設定・データ管理」から操作します。

1. **ZIPに書き出す**で自分の画像ファイルと `album.json` をまとめて保存します。個人の写真が含まれます。
2. 移行先で**ZIPから復元**を選び、書き出したファイルを読み込みます。形式・整合性・写真の読み込みをすべて確認してから、一括で登録します。
3. 同じIDの写真は既存の内容を優先してスキップします。日付やコメントを含めて上書きしません。復元した枚数とスキップした枚数を表示します。

保存容量の目安と永続ストレージのリクエストは、対応ブラウザの設定画面に表示します。永続化の可否はブラウザが決めます。

## 構成

| パス | 役割 |
| --- | --- |
| `index.html` / `src/style.css` | ページ構造、レスポンシブレイアウト、チェキのスタイル |
| `src/main.js` | アルバムの表示、フィルター、表示切替、詳細画面 |
| `src/memories.js` | サンプルの読み込み、日替わり抽選、並び替え |
| `src/ui.js` / `src/animations.js` | チェキとモーダルの共通処理、スクロール時の登場演出 |
| `src/editor.js` / `src/photos.js` | 登録・編集・削除、画像の形式確認とプレビュー |
| `src/storage.js` | IndexedDBの読み書き、重複を除いた一括復元 |
| `src/settings.js` / `src/backup.js` | データ管理画面、ZIPの読み書き |
| `public/sample/` / `src/sample-data/favorites.json` | サンプル画像と登録情報 |
| `public/fonts/` | 画面で使う字形を収録したInter、Noto Sans JP、Noto Serif JPと各ライセンス |

HTML、CSS、Vanilla JavaScript、Viteを使用しています。ZIP処理にはzip.jsを使用し、必要になったときに読み込みます。

## サンプル写真を追加する

公開してよい画像を `public/sample/` に置き、`src/sample-data/favorites.json` の配列に1件追加します。既存のIDは日替わり選出にも使うため維持してください。

```json
{
  "id": "sample-your-photo",
  "image": "your-photo.webp",
  "date": "",
  "alt": "写真に写っている内容",
  "tags": []
}
```

撮影日は判明していれば `YYYY-MM-DD` で指定します。不明な場合は空欄にします。`location` と `comment` は任意です。初期の18枚は向きと縦横比を維持し、長辺最大1800pxのWebPに変換しました。撮影日を取得できた13枚に日付を設定し、画像側のEXIFを取り除いています。

## 表示の調整

`src/style.css` の `:root` に色・余白・サイズがあります。

| 変数 | 変更する内容 |
| --- | --- |
| `--background`, `--surface`, `--ink`, `--muted`, `--line`, `--accent` | 背景、紙、文字、境界線、アクセント色 |
| `--spring`, `--summer`, `--autumn`, `--winter` | 撮影月に応じた色。3〜5月が春、6〜8月が夏、9〜11月が秋、12〜2月が冬 |
| `--season-opacity`, `--season-size`, `--season-core` | 季節色の濃さ（0.56）、チェキに対する広がり（190%）、透明に向かい始める位置（35%） |
| `--content`, `--gutter` | 最大幅と左右の余白 |
| `--float-width`, `--float-span`, `--float-overlap`, `--gallery-gap` | チェキの幅（168〜380px）、左右の配置幅（チェキ幅の2.65倍）、縦方向の重なり、一覧の間隔 |
| `--print-shadow`, `--hover-time` | 影とホバーの時間 |
| `--reveal-time`, `--reveal-rise`, `--ease-out` | 登場アニメーションの時間、浮かび上がる距離、イージング |

`src/animations.js` の `visibleFraction` は、チェキがどのくらい画面に入ると演出を始めるかを指定します。初期値は1枚の25%です。「眺める」では初めてこの位置に届いたチェキが、24px下から600msかけて浮かび上がります。一度見たチェキは表示を維持し、OSの視差効果を減らす設定ではすぐに表示します。

「眺める」の回転設定は同じファイルの `tilt` にまとめています。普段は0°です。短い区間で平均したスクロール速度が、同じ方向で開始しきい値以上のまま続くと、左右のチェキが反対向きに傾きます。

| 設定 | 初期値 | 調整する内容 |
| --- | --- | --- |
| `startSpeed` / `endSpeed` | 6 / 3.5 CSS px/ms | 開始に必要な速さと、傾きを維持する最低速度。開始値を上げるほど反応しにくくなります |
| `qualifyMs` | 130ms | 同じ方向に高速入力が続く必要がある時間 |
| `speedWindowMs` / `maxSampleGapMs` | 32 / 65ms | 平均速度を測る区間の最小時間と、入力を連続とみなす最大間隔 |
| `maxDegrees` / `riseMs` | 3° / 500ms | 最大角度と、継続中にその角度まで傾く時間 |
| `holdMs` / `returnMs` | 250 / 800ms | 最後の高速入力から戻り始めるまでの余韻と、0°に戻る時間 |

復帰中は正面まで戻し切り、次の回転には改めて高速入力が必要です。回転のフレーム更新は高速判定の成立から復帰完了まで、表示中のチェキとその季節色にだけ適用します。「今日の2枚」「一覧」と、端末の視差効果を減らす設定では回転しません。
